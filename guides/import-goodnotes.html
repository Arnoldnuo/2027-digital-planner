How to import a digital planner into GoodNotes (and 4 other apps)

GUIDE · UPDATED OCT 2026 · 5 MIN READ

A digital planner is just a PDF with internal hyperlinks — but the import step is where most first-timers trip. Do it right once and the planner behaves like an app: tap a date, land on the page. Here is the exact procedure for the five apps that handle hyperlinked planners best.

GoodNotes 6 (and GoodNotes 5)

GoodNotes is the most popular home for digital planners, and its import flow is the simplest:

  • Save the planner PDF to the Files app (iCloud Drive, On My iPad, anywhere Files can reach).
  • Open GoodNotes. Tap New… → Import and pick the PDF from Files.
  • GoodNotes creates a new document — name it, choose a cover, done.

How to follow links in GoodNotes: tap-and-hold a link until the context menu appears and choose Open link, or switch the toolbar to the hyperlink tool (the finger-with-chain icon) — then every link opens with a single tap. Read mode (the reading-glasses icon) also makes links tappable. In fullscreen pen mode links are disabled on purpose, so you don't jump pages mid-sentence.

Notability

Import via the + menu → Import from Files. Notability opens internal links with a single tap — no special tool needed. If you're planning with a stylus, just be in zoomed writing mode carefully; links fire in normal view.

Noteshelf

From the library, tap + → Import Document and select the PDF. Noteshelf is a favorite for planner users who like realistic paper feel; links open with a single tap.

Noteful

The newest of the bunch: + → Import. Noteful was built with hyperlinked planners in mind — single-tap links, fast page switching, and nested notebook organization.

Xodo (or any PDF app)

Open the PDF from Files with Xodo, or use Open → File in-app. Xodo's "Link" pointer mode makes internal links clickable. Xodo also works on Android and desktop — handy if you want to review your week on a laptop.

Three things that break links (and the fix)

  • Nothing happens on tap — you're in a drawing/pen mode that captures gestures. Switch to the link/read tool (GoodNotes) or normal view.
  • You jumped pages accidentally while writing — that's the flip side of active links; most users keep the link tool off and tap-and-hold only when navigating.
  • The file came from a cloud-share instead of a download — always download the PDF first, then import. Streaming previews often disable links.
